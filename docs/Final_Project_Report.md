# Final Project Report

## Project Overview

The **Heavy Supplier, Inventory & Warehouse Analytics** project analyzed inventory, warehouse, supplier, procurement, customer, and sales data across Weeks 1–10.

* Completed data exploration and cleaning
* Performed inventory and warehouse analytics
* Analyzed supplier and procurement performance
* Performed customer segmentation and RFM analysis
* Developed customer CLV and risk analytics
* Created **one integrated Power BI dashboard** combining the major project KPIs and insights
* Added interactive filters, business charts, KPI cards, and detailed analysis tables
* Organized the complete project in GitHub

The integrated Power BI dashboard provides a consolidated view of:

* Warehouse operations

* Customer segmentation
* Customer CLV
* Customer risk
* Key business KPIs and insights
